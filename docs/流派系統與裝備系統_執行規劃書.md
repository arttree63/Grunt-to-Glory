# 《小兵的故事》流派系統與裝備系統執行規劃書

## 一、規劃目的

本文件用來統一目前《小兵的故事》的系統命名、養成邏輯、UI 呈現與工程實作方向。

本次主要調整：

* 「操練」正式改名為 **流派**
* 「操練點」改名為 **修練點**
* 「操練等級」改名為 **流派等級**
* 裝備不再以大量傳統屬性為核心，而是直接提升 **流派等級**
* 六種流派同時負責：

  * 基礎能力成長
  * 戰鬥風格
  * 技能解鎖
  * 單修／雙修／三修 Build
* 裝備作為流派 Build 的外部調整工具

整體核心理念：

> **玩家不是在點力量、敏捷、智力，而是在決定自己最後會成為什麼樣的劍士。**

---

# 二、正式用詞

## 修練點

玩家可以分配的養成資源。

UI 顯示：

> 可用修練點：9

玩家將修練點投入六種流派。

---

## 流派

目前六種：

1. 武藝｜一刀流
2. 體術｜返刃流
3. 敏捷｜閃影流
4. 魔法｜魔劍流
5. 信仰｜聖劍流
6. 統御｜軍團劍技流

---

## 基礎流派等級

玩家真正使用修練點提升的永久等級。

程式建議名稱：

```text
base_style_level
```

例如：

```text
武藝 Base Lv.82
```

---

## 裝備流派加成

目前穿戴裝備提供的流派等級。

例如：

```text
斬鐵劍
武藝 +8
```

---

## 有效流派等級

實際參與角色數值計算的等級。

公式：

```text
Effective Style Level
=
Base Style Level
+
Equipment Style Bonus
+
Temporary Modifier
```

例如：

```text
武藝 Base 82
裝備 +8
暫時加成 +5

有效武藝 Lv.95
```

---

# 三、六大流派定位

| 流派       | 戰鬥核心     | 專屬狀態 |
| -------- | -------- | ---- |
| 武藝｜一刀流   | 蓄積後高爆發斬擊 | 勢    |
| 體術｜返刃流   | 格擋、借力、反擊 | 不動   |
| 敏捷｜閃影流   | 閃避、高速追擊  | 游刃   |
| 魔法｜魔劍流   | 附魔、元素、爆發 | 魔紋   |
| 信仰｜聖劍流   | 聖傷、治療、護盾 | 聖印   |
| 統御｜軍團劍技流 | 主角與友軍連攜  | 軍勢   |

設計原則：

> 六種不是六個單純能力值，而是六種完整的戰鬥流派。

# 五、基礎數值成長原則

建議數值設計拆成：

## 共通成長

投入任何流派都會獲得。

例如：

```text
HP
ATK
DEF
```

目的是確保：

> 單修任何流派都不會產生完全不能生存或完全沒有輸出的問題。

---

## 流派專屬成長

再依不同流派加入額外權重。

工程上不要直接寫死。

建議：

```text
StyleGrowthConfig
```

例如：

```text
weapon:
  hp_growth
  mp_growth
  atk_growth
  def_growth
  armor_penetration_growth

body:
  hp_growth
  def_growth
  block_growth
```

所有成長值必須可從資料表調整。

---

# 六、流派里程碑

流派不能只提升數值。

隨著等級提高，會逐步解鎖：

* 核心機制
* 主動技能
* 被動技能
* 流派強化
* 純流派奧義

目前建議共同節奏：

```text
每 1 級
→ 基礎數值成長

每 5 級
→ 數值突破或既有機制強化

每 10～20 級
→ 新機制／技能

每 50 級
→ 一次大型質變
```

設計上應避免：

> Lv10 解一個技能，然後 Lv11～29 完全沒有感覺。

---

# 七、前期節奏

玩家 Lv1 不應該只有普通攻擊。

遊戲開始即提供：

## 基礎劍技：重擊

定位：

> 普通士兵都會的基本強力斬擊。

此技能後續會受到不同流派改造。

因此：

```text
Lv1
普攻 + 重擊

Lv5
第一次流派數值突破

Lv10
正式開啟流派核心機制
```

---

# 八、技能分成兩類

## A. 基礎劍技

所有角色都有。

例如：

* 重擊
* 衝鋒
* 橫掃

特色：

> 可以被流派改造。

---

## B. 流派專屬技能

只有特定流派能取得。

例如：

武藝：

* 斷首
* 斷嶽

體術：

* 返刃
* 崩勢反擊

敏捷：

* 影襲
* 燕返

魔法：

* 炎爆斬
* 元素斷界

信仰：

* 聖光斬
* 審判斬

統御：

* 先鋒斬
* 軍團號令

---

# 九、基礎技能的流派改造

例如 Lv1 的：

## 重擊

初始：

```text
180% ATK
```

如果玩家修武藝：

```text
重擊開始受到「勢」強化
```

修魔法：

```text
重擊追加魔法傷害與元素效果
```

修敏捷：

```text
重擊前後搖縮短
游刃高時追加效果
```

所以系統理念：

> 技能不是一直被淘汰，而是隨角色的修練逐漸進化。

---

# 十、單修

如果玩家集中修一種流派：

例如：

```text
武藝 Lv200
```

就取得：

* 最集中的數值成長
* 最完整的一刀流循環
* 純流派高階能力
* 純流派奧義

例如：

> 一刀兩斷

單修定位：

> **把一種戰鬥哲學推到極致。**

---

# 十一、雙修

兩個流派達成條件後：

例如：

```text
武藝 Base Lv100
魔法 Base Lv100
```

解鎖雙流派融合。

雙修分兩層：

## 1. 機制互通

例如：

魔紋 → 勢

勢 → 魔紋

## 2. 融合能力

例如：

### 魔斬

真正同時使用：

* 勢
* 魔紋
* 元素

雙修不建立第三套完整技能樹。

每個組合建議：

```text
1～2 個機制互動
+
1 個代表融合技能或被動
```

---

# 十二、三修

三個流派達成條件後：

解鎖高階綜合能力。

例如：

```text
武藝
+
魔法
+
敏捷
```

可以解鎖：

### 瞬魔斷界

三修設計原則：

> 三個流派的核心機制都必須真正參與。

不能只是：

```text
傷害 +30%
```

三修定位：

> **創造屬於自己的特殊劍術。**

---

# 十三、裝備系統正式定位

裝備不再是另一套複雜的傳統能力系統。

而是：

> **流派 Build 的外部調整工具。**

主要效果：

```text
提高一種或多種流派的有效等級
```

例如：

### 斬鐵劍

```text
武藝 +8
```

角色：

```text
Base 武藝 Lv72
```

裝備後：

```text
Effective 武藝 Lv80
```

角色直接取得 Lv80 應有的戰鬥數值。

---

# 十四、裝備欄位

第一版只做三個。

## 武器

偏：

* 武藝
* 敏捷
* 魔法
* 信仰
* 統御

## 防具

偏：

* 體術
* 信仰
* 統御

## 飾品

偏：

> 改變流派機制。

第一版不新增：

* 頭盔
* 鞋
* 手套
* 腰帶
* 多個戒指

避免管理過度複雜。

# 十六、裝備品質

建議：

## 普通

只有單流派加成。

## 精良

流派加成較高。

## 稀有

流派加成 + 小型特殊詞條。

## 史詩

雙流派／較強特殊效果。

## 傳說

可以真正改變 Build 運作方式。

品質差異重點：

> 不只是數字更大，而是玩法越來越特殊。

---

# 十七、技能解鎖與裝備等級的關係

重要規則：

## 永久技能解鎖主要看 Base Style Level

例如：

```text
武藝 Base Lv100
解鎖一刀極意
```

如果：

```text
Base Lv92
裝備 +8
Effective Lv100
```

只會取得 Lv100 的數值效果。

不會永久學會需要 Base Lv100 的技能。

這可以避免：

> 穿裝備學會技能，脫裝備後技能又消失。

# 十八、傳承裝備

少數特殊裝備可以例外。

例如：

### 無名劍聖的殘刃

```text
武藝 +12

其中部分等級
可計入流派技能條件
```

這種裝備定位：

> 傳承。

不是一般裝備規則。

# 十九、金幣用途

金幣不要用來提升流派本身。

正式用途：

## 1. 裝備強化

例如：

```text
黑鐵長劍 +0
武藝 +5

↓

+5
武藝 +8
```

## 2. Boss 戰利品重骰

例如：

```text
第一次刷新：30 金
第二次：60 金
第三次：120 金
```

## 3. 中後期裝備詞條重鑄

後續才開。

# 二十、裝備強化限制

第一版：

```text
+0 ～ +5
```

即可。

不要做到 +20 或 +50。

原因：

玩家必須願意換裝備。

過度強化會讓玩家對舊裝投入太多而不願更換。

# 二十四、雙修 UI

六個流派可用六角形配置。

當兩個流派達到融合條件：

兩個流派之間的連線亮起。

例如：

```text
一刀流 Lv100
↕
魔劍流 Lv100
```

顯示：

> 新融合：魔斬

玩家能一眼理解：

> 這兩條路開始連在一起。

# 二十五、三修 UI

形成一個發光三角。

中央：

顯示綜合能力。

> 瞬魔斷界

# 二十七、像素戰鬥方向

目前戰鬥美術方向：

> **高質感日系像素角色 + 少量人物動畫 + VFX + 程式演出。**

不是：

> 把完整動畫 RPG 做成像素版。

第一版人物動畫：

```text
Idle
Run
Attack
Heavy Attack
Block
Hit
Death
Special Pose
```

控制約：

> 30 幀左右。

流派差異主要交給：

* Slash VFX
* After Image
* Hit Stop
* Screen Shake
* Element FX
* Holy FX
* Army FX

---

# 二十八、工程演出框架

sound_id

# 三十五、最終設計原則

整個系統可以用四句話統一：

> **流派決定我是誰。**

> **技能決定我怎麼打。**
