# 《小兵的故事》遊戲機制 × 心理機制

> 2026-07-30。這份文件回答一個問題:**每個系統存在的心理學理由是什麼。**
> 機制清單見〈設計總覽〉,數值見 game-balance skill;這裡寫的是「為什麼玩家會想繼續」。
> 全部對照已實作的系統,不含未落地的設計。

---

## 零、一句話版本

> 玩家扮演的不是一個角色,是一個**家族**。每一代小兵都會退場,
> 但每一代都留下一點什麼——遊戲的所有心理設計都在服務這個承諾:
> **時間不會白花,選擇會留下痕跡,而下一次總是有新的期待。**

---

## 一、地基:兩條不可違反的心理契約

一切機制之上有兩條契約。任何新設計違反其一,其他做得再好都會垮:

### 契約 1:掛機不受懲罰(放置遊戲的根本承諾)

玩家關掉遊戲的那一刻,心裡要篤定「回來時會更好」。所以:

- 離線收益照算(6 折、4 小時上限——打折是為了讓「上線」仍有意義,不是懲罰離線)
- 命運點離線累積(上限 2),滿了**停發但不停推進**——回來不必連點十次補作業
- 決策點永不暫停遊戲:留存事件進「旅途紀錄」等你回來,限時事件錯過就錯過、絕不承載必要內容
- 點擊的所有價值(戰意、爆發、昂揚)對掛機玩家是**加分項不是門檻**:
  調校鐵律是「點擊把差一點過不了變成過,而不是不點就過不了」

**心理機制:安全感。** 焦慮型的留存(不上線就虧)短期有效、長期招恨。
這個遊戲選擇的是「回來永遠是好消息」。

### 契約 2:沒有唯一最佳解(選擇必須真的是選擇)

四維天賦死掉的原因寫在 content-design:四個屬性都在 DPS 一條尺上比大小,
實測全點力量 ×16.21、次佳 ×7.53——**當選項可以換算,選擇就是假的**。由此定下:

- 命運節點是機制不是數值(「武器可以吃武器」vs「攻擊 +5%」)
- 流派差距硬上限 15~25%,超過就會被攻略換算成標準答案
- 傳說與套裝 power-neutral(單件 ±10%):差異來自「怎麼打」,不是「打多少」
- 圖鑑獎勵拓寬玩法、不加常駐傷害——否則收藏變作業、老玩家數值固化

**心理機制:自主性(autonomy)。** 玩家要的不是最佳解,是「這是我的玩法」。
一旦社群算出唯一解,所有選擇介面都變成雜訊。

## 二、五層期待循環(時間尺度 × 心理鉤子)

任何版本上線前的驗收標準:五層中任何一層是空的,那個版本就不會好玩。

| 尺度 | 玩家心裡的問題 | 對應系統 | 心理機制 |
|---|---|---|---|
| **10~30 秒** | 下一次會出現什麼? | 掉落、印記疊層、傭兵招牌行為、戰意快滿了 | 變動比率獎勵(最強的成癮結構)+ 可預期的小節拍 |
| **2~5 分鐘** | 這輪流派開始成形了嗎? | 命運節點二選一、技能覺醒、鍛造開錘 | 承諾與一致性:選了 A 就想把 A 玩出樣子 |
| **10~20 分鐘** | 我會變成什麼? | 二轉逐步揭露(???→傾向→名稱→預覽) | 好奇缺口:知道有答案但還看不到 |
| **一輪結束** | 這一代留下了什麼? | 轉生結算、列傳、傳家之器、圖鑑登錄 | 損失規避的反轉:把「結束」改寫成「收穫」 |
| **多輪累積** | 我的世界改變了什麼? | 勳章科技、矩陣圖鑑、傳說圖鑑、傭兵解鎖 | 稟賦效應:累積的是「我的收藏」,不是進度條 |

下面逐層拆開。

## 三、10~30 秒層:節拍與變動獎勵

### 點擊 = 直接出手(v1.8 定案)

一次點擊 = 一次揮砍 = 一次跳字 = 一次扣血,1:1 不會有空點。
曾經改成「點擊只餵戰意」,理由很工程(避免動畫與血條不同步),
但實玩的回饋是**「點了沒打到東西」比什麼都難受**——
點擊遊戲的第一心理契約是「我的手指有直接效果」。現在兩者並存:
點擊直接傷害(小額,會被層數成長稀釋,所以不會變成門檻)+ 戰意加速自動攻擊。

**心理機制:操作代理感(agency)。** 數值上點擊只值 +21% 推進,
但體感上「每一下都有回應」值遠超過這個數字。

### 戰意:快滿了的張力

點擊疊戰意 → 滿 100 自動爆發歸零。條在畫面上,「快滿了」本身就是 10 秒級的小目標。
Boss/事件窗口內戰意加倍且不衰減——把點擊的價值集中在**二元判定的關鍵時刻**,
「差一點打不過的 Boss,靠我狂點過了」是這一層最強的記憶點。

### 鍛造:賭博結構 + 雙保底

開錘是變動比率獎勵的教科書結構(隨機品質、隨機詞綴、傳說 40% 附帶),
但有兩層保底把挫折封頂:30 次必出紫、50 次必出**帶傳說特性**的傳奇。
保底計數器**常駐可見**——「還差 7 次」把壞運氣轉譯成進度。

**心理機制:賭博的興奮 + 確定性的地板。** 純賭博留不住人(壞運氣會勸退),
純保底沒有驚喜。可見的計數器讓每次落空都變成「離保底更近」,挫折被回收成期待。

### 傭兵:低頻高辨識度事件

每 8~15 秒一次招牌行為(背刺/凍結/砲台/點燃),不做高頻普攻。
設計判準寫在 v1.5:玩家要能說出「**剛剛盜賊跑去背刺了**」,
而不是「我好像多了 8% 傷害」。光環式的被動數值 = 穿了角色外皮的詞綴,已作廢。

**心理機制:可敘述性。** 人記得住事件,記不住百分比。
能被說出來的機制才會被推薦給朋友。

## 四、2~5 分鐘層:承諾與流派成形

### 命運二選一:排斥才有重量

每個決策點二選一,**選了另一個本輪永久關閉**。沒有洗點。
這是刻意的:可反悔的選擇沒有重量,玩家會兩個都試然後查攻略;
不可反悔 + 每輪重選 = 「這輪走 A,下輪想試 B」——排斥本身製造重玩動機。

**心理機制:承諾一致性 + 適度的損失。** 每輪 40 分鐘的損失上限讓「選錯」可以承受,
承受得起的損失才敢做有趣的選擇。

### 總攻 loop(v1.6):玩家自己組出來的爽

對照 Clicker Heroes 補上的三層,核心原則是 **loop 是玩家組的,不是系統送的**:

```
疊視窗(buff 併存,乘區相乘)→ 視窗擊殺攢印記 → 滿層引爆
 ├→ 戰意昂揚 +2%/層(輪內永久,轉生歸零)
 ├→ 引爆回轉:其他冷卻 −0.4s/層 → 更快開下一輪
 └→ 破 Boss → 乘勝推進 12 秒衝層
```

三個心理設計藏在細節裡:

1. **滿層才給昂揚**——保留「現在引爆還是再疊」的決策張力,不會退化成無腦速引
2. **全技能就緒時整排金光**——把「留著一起放」從攻略知識變成畫面提示,總攻有儀式感
3. **昂揚轉生歸零**——輪內 compounding 給「這輪再 loop 一下」的癮,
   又不會像舊勳章的超線性一樣跨輪失控(那個實測第 5 輪傷害暴衝 ×34,已作廢)

**心理機制:能力感(competence)+ 節奏的鋸齒化。** 平滑的成長曲線沒有記憶點;
卡牆 → 總攻 → 暴衝 → 再卡,鋸齒的每個尖峰都是一次「我做到了」。

## 五、10~20 分鐘層:好奇缺口

### 二轉逐步揭露

Lv.20 一轉時只給「三個模糊的方向」;取得命運節點後傾向亮起;再來揭露名稱;
接近 Lv.100 給完整預覽。**不可從 Lv.1 就顯示二轉**——
一次亮出全部 = 沒有問題可以懸著。

轉職文案的立場也是心理設計:不是「恭喜轉職」,而是
「**你在這一輪做出的選擇塑造了這個職業**」——把系統的贈與改寫成玩家的作品。

### 空格是預告,不是留白

技能列的空格寫解鎖條件(「再推進到第 25 層」),未收錄圖鑑顯示剪影 + 線索
(「用陣地基底精工鍛造鎧甲」),**絕不顯示問號**。
「還有東西要來」和「內容沒做完」在畫面上是同一件事,差別只在有沒有寫出來。

**心理機制:蔡加尼克效應(未完成的事記得最牢)。** 問號是死的,線索是活的目標。

## 六、一輪結束:把死亡寫成故事

### 轉生 = 結算,不是清空

結算頁四件事:這一代是誰、走了哪條路、**本代帶來的永久變化**、
下一個已經很近的目標。歸零的畫面一秒都不能單獨存在——
玩家看到的永遠是「得到了什麼」,不是「失去了什麼」。

### 列傳:每一代自動寫進歷史

「第七代・洛恩,重裝步兵→鐵壁工匠,神匠命運,止步於第 86 層,
以裂痕王盾留下傳家之器。」措辭鐵律:**不可寫死**(遊戲沒有玩家 HP)——
用「時限耗盡」「遠征止步」。小兵不是死了,是把棒子交出去了。
這條有單元測試直接斷言結局文字不含「死/殺/陣亡」。

### 傳家之器:雙重期待的鉤子

銘刻一件 → 轉生**必定**回來,但以殘缺版出現(保機制不保強度),
本輪擊破 3 個 Boss 修復。製造兩層期待:
「它會回來嗎」(轉生瞬間揭曉)→「這輪能修好嗎」(前 10 分鐘的目標)。
它**不佔**攜帶名額——付過勳章買的科技價值不被新系統稀釋,這也是心理契約:
**已經給玩家的東西,永遠不拿回來。**

**心理機制:損失規避的正面利用。** 轉生本質是刪檔,
是整個類型最反直覺的操作;所有這些包裝的目的只有一個——
讓玩家按下退役鍵時的情緒是「換一代接棒」而不是「歸零重來」。

### 隨機性的位置:驚喜只加分,不阻斷

固定獲得(勳章、圖鑑、列傳、鐵匠鋪經驗)+ 可能額外獲得(異變、稱號)。
**核心進度不可隨機消失,隨機只負責讓結果偶爾超出預期。**
反例是把「傳家之器回不回來」做成 50% 擲骰——已改成必定回來,
因為跨代承諾禁不起壞運氣:一次「沒回來」毀掉的信任,十次驚喜補不回來。

## 七、多輪累積:收藏,不是數值

跨輪保留的東西刻意分成兩種性質:

| 類型 | 內容 | 心理角色 |
|---|---|---|
| **成長**(數字) | 勳章科技(乘算)、鐵匠鋪等級、保底計數 | 「下輪會更快」的確定感 |
| **收藏**(記憶) | 傳說圖鑑、矩陣圖鑑(記首次達成的**代數**)、列傳、傭兵 roster | 「我的世界在變大」 |

矩陣圖鑑是長期玩法的地圖:3×3 職業×命運,每格記「第幾代達成」。
它不給任何加成——給的是**下一輪的理由**(「還沒試過斥候×神匠」)。

**心理機制:稟賦效應 + 完成主義。** 數值成長會通膨(下一級永遠只是更大的數字),
收藏不會——第 3 代達成的那格永遠寫著第 3 代。

## 八、爽感的物理層(所有心理機制的載體)

心理設計最終都要通過畫面兌現,這層的鐵律:

- **狀態可見性**:任何影響輸出或改變技能行為的狀態,「觸發前→生效中→結束」三段都看得見。
  看不見的機制等於不存在——傳說裝曾經全部隱形,玩家只感覺到數字,就是「少了什麼」的主因
- **事件-演出對照表**:每個 core 事件都要有演出或明示豁免(曾經 20 個型別有 10 個無人監聽)
- **可敘述的行動者**:同一份傷害,拆給分身/軍旗/傭兵各自出手跳字,總量不變、體感完全不同
  (分帳不加量——爽感不必花數值預算)
- **前進感**:地面流線 + 踏步塵土 + 進層衝刺;Boss 戰與事件時停下(那是駐足的時刻)
- **破壞性操作的反面**:一鍵分解永不吞傳說/套裝/傳家之器——
  爽感的最大敵人不是無聊,是**被系統背叛一次**

## 九、已知張力(誠實區)

這些是設計上互相拉扯、還沒有完美解的地方:

1. **power-neutral vs 撿到傳說的興奮**——傳說不變強,興奮全押在「玩法改變」上;
   如果玩法差異的呈現不夠(視覺、構築關係標示),玩家會覺得傳說「沒用」。
   目前靠「不顯示戰力%、顯示構築關係」硬撐,長期要靠演出兌現
2. **排斥型二選一 vs 收集慾**——選了 A 這輪就看不到 B,重玩動機與「這輪不完整」的焦慮是同一個機制的兩面
3. **鋸齒節奏 vs 掛機承諾**——總攻 loop 獎勵主動操作,掛機玩家拿不到昂揚;
   目前守住「掛機曲線不變」,但兩族群的體感差距會隨 loop 內容加深而拉大
4. **首輪長度的方差**——鍛造運氣讓 36~75 分都可能,超出 30~45 的目標帶;
   保底封了下限,上限還沒封
5. **tactician 弱勢化**——loop 紅利(印記→昂揚)被神匠(上限+5)與獵人(事件+3)吃走更多,
   純戰鬥流反而墊底,與它「連斬流」的幻想不符

## 十、速查:機制 → 心理機制對照表

| 機制 | 心理槓桿 |
|---|---|
| 點擊直接傷害 | 操作代理感 |
| 戰意條 | 短期目標張力(快滿了) |
| 鍛造 + 可見保底 | 變動獎勵 + 挫折回收 |
| 命運二選一(排斥) | 承諾一致性 + 重玩動機 |
| 二轉逐步揭露 | 好奇缺口 |
| 空格寫條件 / 剪影寫線索 | 蔡加尼克效應 |
| 總攻窗口 + 金光提示 | 能力感 + 儀式感 |
| 戰意昂揚(輪內疊乘) | 即時 compounding 的癮,封在一輪內 |
| 乘勝推進 | 節奏鋸齒的尖峰 |
| 轉生結算 + 列傳 | 損失規避反轉(結束→收穫) |
| 傳家之器殘缺→修復 | 跨輪雙重期待 |
| 矩陣/傳說圖鑑 | 稟賦效應 + 完成主義 |
| 傭兵招牌行為 | 可敘述性 |
