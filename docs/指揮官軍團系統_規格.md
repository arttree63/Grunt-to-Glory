# 指揮官職業:軍團系統規格(2026-08-02 定案)

> **這是設計裁決,不是提案。** 用戶已拍板,工程照此實作。
> 與舊文件衝突時以本檔為準,並回頭修舊文件而不是繞過它。

## 〇、這個系統要達成什麼

> **我練不同操練,就真的變成不同的指揮官。**

不是「每個兵種都有技能」,是**五種節奏**。

---

## 一、四條原則(所有實作都要過)

| # | 原則 | 判準 |
|---|---|---|
| 1 | **常駐效果一定影響戰鬥節奏** | 不可以是「+10% 傷害」。要看得出來:士兵變快、多打一刀、火焰一直燒、盾牌一直舉、補血一直跳 |
| 2 | **號令一定是高潮** | 平時慢慢累積特色 → 軍勢滿 → 號令 → 瞬間爆發。玩家要**期待**按它 |
| 3 | **英雄永遠第一順位** | 不可以變成「士兵自己在玩」。英雄一定還是主角 |
| 4 | **五兵種 = 五種節奏** | 不是五種數字 |

⚠️ 原則 3 的落地寫法:**每個號令的收尾都是英雄**(見下方各兵種)。

---

## 二、★ 最大的機制改動:號令不清空軍隊

**改前**:`armsCommand` 要求 `armyUnits` 滿格,施放後 `armyUnits = 0` ——
玩家看到的是**軍隊憑空消失**,所以會把軍勢當成 MP。

**改後**:

```
軍勢滿 → 號令可用 → 施放 → 號令進冷卻 → 軍勢重新累積 → 再次可用
```

**士兵留在場上不消失。**

> 軍勢代表的是**士氣**。滿了代表「士氣高昂,可以發號施令」;
> 發令後士氣不會瞬間消失,而是需要時間重新凝聚。
> 這樣軍勢是**戰場節奏**,不是另一條法力值——也才符合「身先士卒的傳奇指揮官」。

⚠️ **工程注意**:現行號令威力是 `1 + 消耗士兵數 × 0.12`,靠「消耗」定價。
不再消耗之後這條定價失效,威力要改由**冷卻**與**編制**決定,需要重新配平。
順帶:這也解掉先前回報的「下個技能施放完士兵還會不見」。

## 三、五兵種:常駐 + 號令

### ⚔ 武藝 — 先鋒軍

| | |
|---|---|
| **常駐** | **協同追擊**:英雄每施放一次技能,所有先鋒**立即補一刀**。⚠️ 不是固定時間間隔 |
| **號令** | **列隊衝鋒**:所有先鋒依序衝鋒,每位一段 → **英雄補最後一記重擊** |

**為什麼是「跟著技能」而不是計時器**:玩家會感覺「我一出招,大家跟著衝」——那就是身先士卒。
⚠️ 號令的收尾**必須是英雄**,不是「士兵打完就結束」。

### ❤️ 體能 — 盾衛軍

| | |
|---|---|
| **常駐** | 英雄受擊 → **盾兵反擊**。看得見,比單純減傷有趣 |
| **號令** | **盾牆推進**:全隊 3~5 秒**霸體**,敵人攻擊全部撞盾。**不打傷害** |

玩家的感受是「我終於可以安心輸出」——號令的價值不一定要是傷害。

### 🏹 身法 — 游擊軍

| | |
|---|---|
| **常駐** | 每次協同 → **累積破綻**(印記)。玩家一直看到印記增加,最好理解 |
| **號令** | **影襲**:所有游擊兵高速多段、全部累積破綻 → **英雄瞬移一刀** |

⚠️ **不叫「左右包夾」**——單體引擎做不到位置。但高速多段 + 瞬移收尾,
**玩家會以為真的被包圍**。(`keywords.ts` 的 `displace` 標記為 `presentation_only`,
只做演出、不作為邏輯判定,與此一致。)

### 📖 魔法 — 法師軍

| | |
|---|---|
| **常駐** | **一直燃燒**。最好辨識的常駐 |
| **號令** | **元素詠唱**:五個法師同時放 → 火 → 冰 → 雷 → **一起爆炸** |

### ✝ 信仰 — 祭司軍

| | |
|---|---|
| **常駐** | **一直回血**。玩家一直看到綠字,最直觀 |
| **號令** | **聖域**:所有祭司舉杖 → 大型光圈 → 回血 + 減傷 + 淨化 |

整隊續航。

---

## 四、混編 = 軍團共鳴(不是另一招)

⚠️ **不做「盾+法 = 另一招」**,太複雜。改成**被動共鳴**:

| 組合 | 共鳴 |
|---|---|
| 盾兵 + 法師 | 法師站盾後 → 所有法術**增加穿透** |
| 游擊 + 先鋒 | 游擊先上破綻 → 先鋒**暴擊** |

這是「配合」,不必另外做一招。號令仍然只有一個,效果照編制走。

---

## 五、衝鋒(英雄技能)= 身先士卒

**不要傷害提升。**

衝鋒後 **6 秒**:
- 所有士兵**協同攻擊速度提升**
- **軍勢累積速度提升**

形成循環:

```
衝鋒 → 全軍士氣高漲 → 一直追打 → 軍勢很快又滿 → 再次號令
```

**這就是指揮官。**

⚠️ 工程註記:選「速度」而不是「傷害倍率」,在本專案「傷害 = DPS × 累積時間」的模型下
是**傷害中性**的——提升的是破盾與印記的累積速度、以及軍勢節奏,不是數字膨脹。
符合 power-neutral 原則,但需要演出配合才看得懂。

## 六、工程待辦(不需用戶裁決)

1. **號令改為不清空軍隊**:`armsCommand` 的 `s.armyUnits = 0` 拿掉,
   門檻改為「軍勢滿」,施放後進冷卻。⚠️ 威力定價要重配(見 § 二)
2. `ArmyUnitType` 由 2 種擴到 5 種,存檔白名單遷移(只擴不縮)
3. `tickArmy` 依兵種分岔常駐效果;先鋒的常駐改掛在**技能施放事件**上,不走計時器
4. 號令改為「讀編制 → 查表 → 執行」,不再是固定 burst
5. 軍團共鳴:讀編制組成,套被動修正
6. 衝鋒加 6 秒 buff(協同速度 + 軍勢速度)
7. **五格回退**:⚠️ 線上已有玩家存 6 格編制,`sanitizeArmyFormation` 只補不縮,要處理
8. 五兵種素材與演出(依 `game-visual` 的分類門檻驗收)
