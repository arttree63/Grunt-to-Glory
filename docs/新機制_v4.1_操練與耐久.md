# 《小兵的故事》新機制整理

> 2026-08-01 · 本次對話決定的內容
> ⚠️ 這份文件**取代**舊 GDD v3.0.2 中衝突的部分,不受舊約束限制。舊文件僅作參考,實際以此為準。

---

## 1. 關卡推進

```
推進 → 撞牆(死亡)→ 退回上一層,駐守
                          ↓
                    駐守期間持續產出(素材/金幣/經驗)
                          ↓
                玩家按「挑戰下一層」才再嘗試
```

- 每層**滿血進場**
- 死亡**不扣任何永久進度**
- 不自動重試,由玩家主動觸發
- 無限往上推,系統自然停在玩家的真實極限層
- 魔王(每 10 層)解鎖後可單獨重複挑戰,不用重爬

---

## 2. 血條(遠征耐久)

- 單場戰鬥的容錯額度,**每層重新滿血**,不跨層記帳
- 死亡 = 這層失敗,退駐守,無其他懲罰
- 兩條檢定分工:
  - **倒數** → 你打得夠快嗎(輸出)
  - **血條** → 你擋得住場上威脅嗎(生存)

---

## 3. 操練 = 等級

**沒有獨立角色等級。操練點數總和就是總等級。**

例:30 級 = 五科加總 30 點,玩家自由分配,可以全押一科。

### 五科屬性表

| 操練 | 主屬性 | 次屬性 |
|---|---|---|
| ⚔ 武藝 | 攻擊力 | 防禦力 |
| 🛡 體能 | 耐久上限 | 回血(被動,持續回復) |
| 🏹 身法 | 爆擊率 | 迴避 |
| 📖 魔法 | 魔法攻擊力 | MP(回復速度) |
| ✝ 信仰 | 回血量(觸發式) | debuff 抗性 |

**爆擊率、迴避為全域生效**,不分傷害來源(近戰/魔法/點擊皆吃),不像主屬性分科。這是身法可以跟任何科目組合出玩法的關鍵。

### 數值雙層結構

```
最終數值 = 基礎成長(吃總等級) + 分配加成(吃該科點數)
```

| | 基礎成長 | 分配加成 |
|---|---|---|
| 吃什麼 | 總等級,全五科都有 | 該科實際點數 |
| 力度 | 小(暫抓約 1/5) | 大,決定風格 |
| 目的 | 沒點的科目也有基本水準,不會脆到不能玩 | 選擇仍決定強項 |

### 點擊傷害

**改吃「武藝攻擊力」,不吃總 DPS。** 沒點武藝的人,點擊自然偏弱——這是「魔法流靠連續施法、武藝流靠點擊+普攻」兩種身分成立的關鍵。

---

## 4. 職業與操練的關係

**門檻全職業相同,差異放在產物,不放在門檻。**

同一個操練組合門檻,三職業解鎖出不同的東西(依既有資源系統:陣位/破綻/法令)。

- 職業只定義:資源規則 + 節點產物路由 + 專屬節點 + 效率係數(0.85~1.15)
- 效率係數只影響數值產出,不影響節點是否解鎖

### 啟用上限

節點解鎖是永久的,但**同時啟用有上限 N**。駐守時可免費重配——這讓「重配節點」變成撞牆後的第一解法。

---

## 5. MP 制(取代冷卻)

```
現行判定:冷卻時間到 → 施放
改為判定:MP 夠了 且 已過最短 CD → 施放
```

- 平常技能(前三格)吃 **MP 為主要限制**,疊加一個很短的保底 CD(1~2 秒),防止 MP 瞬間回滿時同一技能連續觸發好幾次
- 頂點技能(第四格)維持**正常 CD**,不受 MP 影響,保留大招稀有感
- **MP 基礎回復速率固定**,不綁定魔法科 → 魔法不會變成全職業必練的稅
- 魔法科的加成 = **回復速度**,不是池子上限 → 這樣才會做出「連續施放」的手感,而非只是撐久一點的爆發

---

## 6. 轉生

**轉生 = 重練。** 按下轉生:操練點數歸零,重新分配。

- 傳家之器、圖鑑、勳章 **不受影響,保留**
- 這是撞牆制底下轉生唯一的觸發方式(死亡不再結束一輪,轉生必須由玩家主動按)

---

## 7. 目前留白(之後再說)

- 生活類技能(鍛造、藥草...)如何影響戰鬥,暫不算入操練總等級
- MP 具體數字(上限、基礎回復速率)
- 各科組合技能的完整表(目前只有武藝×體能、武藝×身法、武藝×鍛造、武藝×魔法、信仰×魔法五對有雛形,五科兩兩配對共 10 種)
- 啟用上限 N 的起始值與成長節奏
- 血條在關卡內怎麼回復(可能跟藥草有關)

### 實作與規格的差異(誠實記錄)

1. **§3「基礎成長 + 分配加成」改成有界乘區,不動指數。**
   這款成長是指數的(傷害 1.045^lv、怪血 1.16^floor)。若讓分配去改指數,
   全押一科與平均分配在第 300 層會差好幾百萬倍。現在:
   `分配加成 = 0.6 + 2.0 × 該科佔比` → 平均 ×1.0、全押 ×2.6、不點 ×0.6。
   在指數曲線下 ×2.6 約等於「多推 6 層」——有感,但不會炸掉平衡。
2. **點擊傷害吃武藝**是透過武藝乘區進 DPS 達成的(點擊傷害本來就按 DPS 計),
   沒有另外做一套點擊公式。沒點武藝的人點擊自然偏弱,符合 §3 的意圖。
3. **§5 的 MP 成本**訂為「該招原本的冷卻秒數 × 基礎回復速率」,
   所以平均分配的玩家施法頻率與改版前一致,魔法科靠回復速度做出連續施放。
   池子 400(裝得下最貴的一招),不隨等級長。
4. **CD 相關的既有裝備全部改吃 MP**(倒轉沙漏/引爆回轉/追風者之靴/冷卻縮減詞綴)。
   不轉的話它們在 MP 制下等於死裝備,而且玩家不會知道——這是靜默失效。
5. **§2 的「上次失敗:後排弓手…」還做不到**:戰鬥模型是單目標,
   多目標是阻擋項(見 GDD修訂_v4.0-A § 7)。耐久第一版的扣血來源是**機制式的場上威脅**,
   不是具體的敵人編組。
6. **耐久上限的基準刻意除掉武藝乘區**,否則練攻擊會連帶變肉,體能就沒有存在意義。
7. **MP 不隨樓層補滿**(耐久才是每層額度),否則清層快的人等於無限法力。

### 架構決策

- **耐久是單場暫態,不進存檔**:與 `shellLeft` / `channelLeft` 等 Boss 機制暫態同級,
  `spawnEnemy` / 進新樓層時重設滿值。讀檔時既有的「Boss 戰重開那一場」規則會自動歸位。
- **耐久上限只有一支衍生函式**(`enduranceMax`):game-balance skill 的硬規則——
  任何會被科技/詞綴/命運節點修改的量,只能有一個算法。批次 2 先吃總等級,
  批次 3 改吃體能點數,消費端不必動。
- **死亡與 Boss 逾時共用同一條失敗路徑**(`failFloor`):否則越戰越勇、家族宿敵、
  失敗診斷會對新的失敗形態全盲,而且是靜默的。
- **`bossRetryFloor` 欄位沿用**(已進存檔、已有測試),語意擴大為「待挑戰的樓層」;
  UI 文案依該層是不是 Boss 層而變。
