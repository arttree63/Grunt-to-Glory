# 第一版核心收斂(2026-08-02 定案)

> **這是最終決策。** 與所有舊文件衝突時以本檔為準。

## 〇、要解決的問題

不是內容不夠,是:

> **玩家不知道遊戲到底在玩什麼。**

## 一、核心一句話(整個企劃的錨)

> **操練不只是讓你變強,而是讓更多人願意追隨你。**

這一句解釋整個系統:
- 為什麼**先練本體,再有軍團**
- 為什麼**軍勢來自戰鬥,而不是魔力**
- 為什麼**兵種是操練的成果,不是一開始就有**

## 二、第一版只有四個系統

```
英雄
 ↓
操練(永久成長)
 ↓
技能(戰鬥)
 ↓
軍勢(戰鬥資源)
```

**沒有**:命運、戰意、軍團共鳴、旅途。玩家先把這四個玩懂。

| 系統 | 狀態 |
|---|---|
| 戰意 | ✅ **已完全移除**(`9ecc150`) |
| 命運 | 隱藏(保留程式碼,關入口) |
| 軍團共鳴 | 不做,留 v2 |
| 旅途 | 隱藏 |

## 三、拿掉 MP,統一用軍勢

**理由三條**
1. 已經有軍勢了。再有 MP,玩家要同時理解 HP / MP / 軍勢——太多。
2. **世界觀**:英雄一直打 → 軍勢累積 → 技能越來越強 → 號令。合理。
   「為什麼衝鋒要耗魔?」不合理。
3. 軍勢可以取代 MP,而且統一。

**軍勢不是藍條,是士氣。**

```
□□□□□□□□□□  軍勢
```

| 行為 | 累積 |
|---|---|
| 打一下 | +5 |
| 暴擊 | +8 |
| 重擊 | +12 |
| Boss 破盾 | +20 |

玩家會一直想:**我要把士氣集滿。**

**技能消耗**

| 技能 | 消耗 |
|---|---|
| 重擊 | 0 |
| 衝鋒 | 20 |
| 武神姿態 | 100 |
| 號令 | 100 |

## 四、兵是成長的證明,不是起點

**Lv1~49 一個人成長;Lv50 起因為你的成長,開始有人追隨。**

| 等級 | 解鎖 | 玩家的感受 |
|---|---|---|
| Lv1 | 一個小兵,拿木劍,普通攻擊 | 這就是小兵的故事 |
| Lv10 | **重擊** | 我變強了 |
| Lv30 | **衝鋒** | 開始有英雄特色 |
| **Lv50** | ★ **先鋒軍加入** | **哇——玩了五十分鐘,終於有人跟著我** |
| Lv80 | **先鋒號令** | |
| Lv100 | **武神姿態 / 皇家近衛** | 我真的不是小兵了,我是指揮官 |

> 這比一開始就送五個兵有感動太多。
> 「出生 → 五個士兵」很怪;「越來越多人相信你」才是這個遊戲的名字。

## ⚠️ 五、兩處與先前裁決衝突,需要拍板

### 衝突 A:號令到底消不消耗軍勢?

| 來源 | 說法 |
|---|---|
| 先前裁決(§ 軍團系統規格 二) | **不消耗**。軍勢滿 → 可用 → 進冷卻 → 重新累積。理由:軍勢是士氣,發令後不會瞬間消失 |
| 本次 | 號令**消耗 100 軍勢** |

⚠️ 現行 `ARMY_MOMENTUM_MAX = 100`,所以「滿」與「100」**數值上同一件事**,
但**行為不同**:消耗 = 按完歸零;不消耗 = 按完進冷卻、士氣還在。

兩者對「玩家看著條子的心情」影響完全不同:
- **消耗**:條子歸零 → 重新集氣 → 期待感來自「快滿了」
- **不消耗**:條子留著 → 冷卻中不能按 → 期待感來自「冷卻好了沒」

**待拍板。**

### 衝突 B:等級階梯數字對不上現行資料

| | 重擊 | 衝鋒 | 先鋒軍 | 號令 | 武神姿態 |
|---|---|---|---|---|---|
| 本次裁決 | Lv10 | Lv30 | **Lv50** | Lv80 | Lv100 |
| 現行 `trainingTree.ts` | Lv20 | Lv50 | (無獨立節點) | Lv100 | Lv200 |

⚠️ 現行沒有「先鋒軍加入」這個獨立里程碑——士兵是靠軍勢滿自動召喚的,
與「Lv50 第一次有人追隨」的敘事完全對不上。這是本次裁決**最需要新做**的一塊。

同時要重新確認:改階梯會動到成長曲線(見 `game-balance` skill 的節奏漂移記錄)。
