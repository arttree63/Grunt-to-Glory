## 零、動手前必讀

- 演出全部走 `src/render/BattleScene.ts`,由 `src/ui/BattleCanvas.tsx` 監聽 core 事件轉發。
  **core 不碰畫面**,需要新資訊時是往 `GameEvent` 加欄位,不是讓 render 去讀邏輯。

- 非主角實體上限(v1.5 § 六):常駐人形 ≤2、短時分身 ≤3、場地物件 ≤3、瞬時特效不計入。
- 跳字節流已有規格:普通 160ms / 暴擊 100ms / 金幣 220ms、5 格錯位、同屏上限 12。新效果不要另開一套。

## 一、P0:三招沒有身分(最優先,core 端已就緒)

現況:盾牆突擊、疾風連刺、聖光審判在畫面上**完全一樣** —— 同一個揮砍弧光 + 一個大金字。
玩家分不出剛剛放的是哪一招,這是所有「技能不夠好」感受的根源。

⚠️ **技能名稱以程式為準**:`src/core/skills.ts` 是唯一依據。
一轉三招是 **盾牆突擊 / 疾風連刺 / 聖光審判**,第二技能是 **軍陣號令 / 追風印記 / 律令標記**。
(設計文件多次出現的「疾影穿刺 / 迴身追獵 / 元素裁決 / 法令輪轉」在程式裡不存在。)

### 1.1 盾牆突擊(重裝步兵)—— 沉重、陣地、壓迫

| 層 | 需要什麼 | 建議做法 |
|---|---|---|
| 施放瞬間 | 盾形衝擊波 | 由主角向前擴散的半透明弧,120ms 內放大並淡出 |
| 持續期間 | 腳下軍陣圓環 + 盾紋 | 沿用 `drawFormation` 的畫法另開一組(金→鐵灰),緩慢旋轉 |
| 攻擊節奏 | 揮擊變慢變重 | 揮砍動畫時間拉長、shake 加倍、impact 放大 |
| 結束 | 軍陣碎裂 | 圓環向外炸開後淡出 |

現況:只有 buff 文字「盾牆突擊 生效中 10.0s」。

### 1.2 疾風連刺(突擊斥候)—— 高速、多段、殘影

| 層 | 需要什麼 | 建議做法 |
|---|---|---|
| 持續期間 | 主角後方半透明殘影輪廓 | 複製 heroSprite 的貼圖,alpha 0.25,延遲 80/160ms 跟隨 |
| 攻擊節奏 | 高頻小揮 | 弧光變細變短、間隔縮短(注意二轉「殘影」進化已經真的縮短攻擊間隔) |
| 跳字 | 小而密 | 這招期間跳字字級 −25%,節流放寬到 120ms |

⚠️ 不可只把原揮砍加速 —— 那看起來只是「普攻變快」。殘影輪廓是這招的辨識點。

### 1.3 聖光審判(隨軍法警)—— 裁定、降臨、瞬間爆發

| 層 | 需要什麼 | 建議做法 |
|---|---|---|
| 前置 | 敵人腳下先出現印記 | 圓形符文 Graphics,150ms 放大 |
| 命中 | 由上方降下光柱 | 直立漸層長條,由上而下擦過,搭配全屏白閃 60ms |
| 痕跡 | 地面印記殘留 | 印記淡出 600ms |
| 跳字 | 獨立樣式 | 白底金邊、字級比暴擊再大一階 |

現況:與所有技能共用 `skillHit()`。

### 1.4 第二技能(印記引爆)

軍陣號令 / 追風印記 / 律令標記共用一份實作,但**引爆演出應該看得出「消耗了幾層」**:
建議引爆時從主角身上射出 N 道光束(N = 消耗層數,上限 10 道),依序命中敵人,最後合成一個大數字。
`skill` 事件已帶 `damage`,需要 core 再補一個 `count`(消耗層數)欄位。
