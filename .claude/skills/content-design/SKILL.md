# 《小兵的故事》內容設計規範 v1.0

> 數值 → `game-balance` skill。介面 → `clicker-ui` skill。本檔管的是「玩法內容怎麼寫」。
> 這些規則都是踩坑後定的,違反其中任何一條都會讓已經解決的問題復發。

## 一、⚠️ 三個前提缺口(提案前必讀)

現行系統**不具備**以下能力。任何設計若依賴它們,必須先做出「要不要引入」的決策,
那是比內容本身更大的工程,不能當成順便做掉的細節。

| 缺口 | 現況 | 曾經踩到的提案 |
|---|---|---|
| **沒有玩家 HP** | 主角不會受傷或死亡,Boss 是限時 DPS 檢定 | 「飲血:開局 −10% HP」「狂戰士:越殘血越強」 |
| **沒有位置與多目標** | 邏輯上一次只有一個 `enemyHp`,畫面上的多隻小怪是**純演出** | 「護陣位置」「範圍攻擊在所有護陣觸發」「攻擊所有帶破綻的敵人」 |
| **沒有元素狀態機** | 沒有元素、沒有反應表 | 隨軍法警的元素流(施加 → 轉換 → 反應) |

代價型設計請改用**已存在的軸**:金幣獲取、素材掉落、技能冷卻、事件頻率、推進速度。

## 二、命運樹節點的寫法

### 節點是機制,不是數值

```
❌ 攻擊 +5%          → 可以跟其他節點用同一把尺比大小 → 唯一最佳解
✅ Boss 死亡掉兩倍素材
✅ 打造有 10% 機率保留素材
✅ 武器可以吃武器
```

四維天賦就是死在這件事上:四個屬性都在 DPS 這條尺上比大小,實測 40 點全投單一屬性,
力量 ×16.21、次佳 ×7.53,**沒有理由不全點力量**。機制之間沒有共同尺度,才不會重蹈覆轍。

### 質變門檻不可寫成數值門檻

```
❌ 冷卻縮減達 30% 時額外 +10% 傷害     → 仍然是數值,一樣會製造唯一解
✅ 同時持有攻擊、範圍、觸發三類鍛印時,鍛印依施放順序組裝成新效果
✅ 同一輪循環中完成「標記 → 追擊 → 再標記」
```

玩家的快感來源是「**原來這三個東西可以組起來**」,不是「我有 37%」。

### 每輪重選,跨輪的東西另外放

命運路徑與節點**每輪重選**,轉生不保留。跨輪的累積放傳承圖鑑與勳章科技。

### 流派差距 15~25%

超過就會被換算成唯一最佳解。實測方法見 `game-balance` skill;
每條流派都要有自己的模擬代理策略,`DESTINY=artisan npm run sim` 可切換。

> ⚠️ **調數值前先確認代理玩家真的會用到它**。曾經把爐火從 +4% 調到 +1.5%,
> 模擬數字**完全沒變**——因為代理素材一夠就開錘,爐火永遠只有 0~1 層。

## 三、事件分兩類(硬規則)

| 類型 | 例子 | 特性 |
|---|---|---|
| **限時事件** | 寶箱怪 / 黃金哥布林(8 秒) | 主動玩家收益高、錯過不阻塞、**不承載必要的流派解鎖** |
| **留存事件** | 神秘鐵匠 / 旅行商人 / 岔路 | 進「旅途紀錄」等玩家回來,**命運相關分支只能放這裡** |

放錯類型會天然懲罰掛機玩家——這是放置遊戲最基本的承諾,不能違反。

同理,**決策點不可暫停推進**:命運點可離線累積(上限 2),滿了停發但遊戲照跑。
玩家掛機八小時回來不該發現自己完全沒推進,也不該要連點十次。

## 四、技能與被動

### 被動用規則型,不用數值型

```
❌ 重裝步兵:傷害 +20% / 聖騎士:傷害 +60%(取代上者)
✅ 陣地意志:每次建立護陣會記錄下一個技能類型,連續不同類型後護陣獲得額外功能
✅ 聖裁:護陣層數達上限時發動範圍審判
```

規則型天然可以並存,「取代 vs 累積」的爭議直接消失,Tier2 也不必重訂數值——
因為 Tier2 不再是「更大的數字」,而是「使用 Tier1 產生的資源」。

玩家的感受從「數字被換掉了」變成「我以前得到的東西,現在有了新用途」。

### 技能格結構:三固定 + 一變動(不硬湊四招)

| 格 | 來源 | 責任 |
|---|---|---|
| 1 | 一轉既有技能 | 定義基本戰鬥方式 |
| 2 | 中期職業覺醒 | 與第 1 格形成循環 |
| 3 | 二轉技能 | 完成流派、產生質變 |
| 4 | **每輪變動** | 傳奇裝備技能 / 命運共鳴 / 遺物技能 |

第四格不必每個職業固定做滿,留給每輪會變的東西——這也讓尋寶獵人有發揮空間。
命運通常**不給新按鈕**,而是改造既有技能的運作方式(被動改造 ×2~3)。

**空格必須寫出解鎖條件**。「還有東西要來」和「內容沒做完」在畫面上是同一件事,
差別只在有沒有寫出來。

### 第二技能的解鎖:命運樹的「職業覺醒節點」

❌ 不要綁 Lv.30~35。實測首輪 Lv.20 在 2.4 分、Lv.50 在 4.2 分,
Lv.30~35 距一轉只有 30~60 秒,心理上等於「一轉附贈」,形不成中期期待。

✅ 採**命運樹固定位置的職業覺醒節點**:三條命運的同一階段都有,
解鎖後旁邊才出現各命運自己的改造節點。這個結構最穩:

1. 玩家先拿到完整的職業循環
2. 命運再修改第二技能
3. **不會因為命運選擇而有人拿不到核心技能**

目標時間點:一轉後約 2~4 分鐘(約第 20~30 層)。

### 職業時間軸(Lv.20 一轉 / Lv.100 二轉)

| 階段 | 時間點 | 玩家獲得 |
|---|---|---|
| 初始 | 開局 | 基礎自動戰鬥,理解裝備 |
| 一轉 | **Lv.20** | 既有主動技能 ×1、核心被動 ×1、第二技能的解鎖條件、三個模糊的二轉方向 |
| 流派成形 | 約 20~30 層 | 職業覺醒 → 第二主動技能 |
| | 約 40~60 層 | 第二技能的命運改造、二轉候選名稱揭露 |
| | 約 70~90 層 | 共鳴被動、二轉完整預覽 |
| 二轉 | **Lv.100** | 二轉主動 ×1 + 二轉被動 ×1 + **既有技能進化 ×1** |

二轉一次給三層內容,Lv.100 才有重量。逐步揭露不可從 Lv.1 就顯示二轉,
也不可把 Lv.20 寫成二轉(曾經發生)。

### 兩個技能要構成最小循環

不能是「一招打傷害、一招打更多傷害」。要有「建立 → 利用」或「標記 → 消耗 → 再標記」的結構。

### 成本控制:共用骨架 × 職業表現

命運技能每條命運只做**一個骨架**,依職業產生三種表現,玩家看見的是三個技能。
不要為每個職業各做一套。

## 四之二、既有技能清單(以程式為準,提案前必看)

| 職業 | 技能 | 實際效果 | CD |
|---|---|---|---|
| 重裝步兵 | **盾牆突擊** | 10 秒內傷害 ×2.5 | 75s |
| 突擊斥候 | **疾風連刺** | 10 秒內暴擊率 +60% | 75s |
| 隨軍法警 | **聖光審判** | 立即造成 25 秒份的傷害 | 90s |
| 聖騎士 | 不動如山 | 15 秒內傷害 ×3 | 70s |
| 影舞者 | 影分身 | 15 秒內暴擊率 +100% | 70s |
| 大元素使 | 隕石術 | 立即造成 40 秒份的傷害 | 80s |

⚠️ 三個一轉技能中,**兩個是 buff 視窗、一個是立即傷害**,都沒有陣地/標記/元素概念。
提案時不可把新設計標成「既有技能」(曾出現「疾影穿刺(既有)」「元素裁決(既有)」,
實際上不存在,那是重做而非補充)。

### 首版採方案 A:保留現有技能,補第二技能形成循環(已實作)

三個職業共用**同一份印記實作**,只有名稱與累積來源不同:

| 職業 | 第二技能 | 印記名 | 累積來源 |
|---|---|---|---|
| 重裝步兵 / 聖騎士 | 軍陣號令 | 軍勢 | 盾牆突擊視窗期間的擊殺 |
| 突擊斥候 / 影舞者 | 追風印記 | 追風印記 | 疾風連刺視窗期間的擊殺 |
| 隨軍法警 / 大元素使 | 律令標記 | 法令 | 每次施放聖光審判 |

循環:**既有技能建立累積 → 印記疊加(上限 10)→ 第二技能挑時機消耗**,
每枚印記折算 3 秒份 DPS。玩家的決策是「現在引爆還是再疊」。

實作要點:三個職業共用 `s.sigils` 一個欄位與一份 `consumesSigils` 分支,
不需要位置、多目標或 HP。新增職業只要指定 `awakenSkill` 與累積來源。

### 命運對印記的改造(已實作)

命運**不給新按鈕**,而是改變印記的累積與使用方式:

| 命運 | 改造 |
|---|---|
| 神匠 | 印記上限 +5(囤積思維,對應「現在打造還是繼續累積」的性格) |
| 尋寶獵人 | **擊破限時事件額外 +3 印記** —— 這是尋寶獵人的戰鬥機制,讓它不只是經濟流 |
| 戰術家 | 連斬每跨 5 層額外 +1 印記(把連斬與印記串起來) |

⚠️ 尋寶獵人這條是關鍵:改造前它在模擬中是最弱的(首輪 161),
給了戰鬥機制後變成最強(首輪 191)。**純經濟型命運撐不起職業分支**這件事在數值上得到驗證。

### 職業覺醒的雙條件(已實作)

`isAwakened()` = 抵達第 25 層 **且** 取得至少一個 tier>0 的命運節點。

- 只用層數 → 變成固定流程
- 只用命運節點 → 受節點出現順序影響
- **不綁特定命運** → 不會有人因為選錯命運而拿不到核心技能

技能列的空格會把還差什麼寫清楚(「再推進到第 25 層」/「取得第一個命運節點」)。

## 五、轉職

- 二轉分支由「一轉職業 + 本輪命運」共同決定,讓兩個系統互相咬合而非平行
- **命運只有三條:神匠 / 尋寶獵人 / 戰術家**。不存在「奧術系」「星命系」「第三命運」,
  提案若出現這些名稱即為錯誤(曾經發生)
- **首版已實作三組命運限定二轉**,各覆蓋一個一轉職業與一條命運;
  其餘六格走通用二轉 + 命運後綴(「聖騎士・神匠系」),玩家的路線仍被承認

| 已實作 | 組合 | 說明 |
|---|---|---|
| 鐵壁工匠 | 重裝步兵 + 神匠 | 軍勢上限再提高 |
| 影陣先鋒 | 突擊斥候 + 戰術家 | 連斬與追風印記互推 |
| 遺物裁定者 | 隨軍法警 + 尋寶獵人 | 事件擊破直接轉法令 |

- 二轉逐步揭露已實作四階段(`revealStage()`):
  `outline`(???)→ `leaning`(命運影響顯現)→ `named`(揭露候選名稱)→ `full`(完整能力預覽)。
  依「取得幾個 tier>0 命運節點」推進,Lv.90 以上直接進 full。

- 3×3 完整矩陣(概念名,其餘六格尚未實作):

| 一轉 | 神匠 | 戰術家 | 尋寶獵人 |
|---|---|---|---|
| 重裝步兵 | 鐵壁工匠 | 破軍將 | 遺跡守衛 |
| 突擊斥候 | 機巧獵手 | 影陣先鋒 | 秘寶追跡者 |
| 隨軍法警 | 鍊成法官 | 軍律術師 | 遺物裁定者 |

- ⚠️ **尋寶獵人必須有戰鬥機制,不能只是掉寶率加成**,否則沒有資格影響二轉分支。
  候選方向(都可用現行單目標模型實作):敵人的寶藏弱點、從菁英/Boss 取得暫時遺物、
  本輪收集不同類型遺物形成套組、掉落留下可供技能消耗的寶物標記、稀有物改造下一次技能
- 成本控制:通用二轉骨架 + 命運變體模組,只替換被動、一個技能變體、外觀與名稱
- **逐步揭露**:輪廓(不公布名稱)→ 傾向亮起 → 揭露名稱與預覽 → 轉職
  轉職不是「恭喜轉職」,而是「你在這一輪做出的選擇塑造了這個職業」
- Tier 0~2 已實作(Lv.20 一轉、Lv.100 二轉)。**Tier3 暫不做**,先確認 Tier1→Tier2 的期待循環成立

## 六、傳承內容

### 列傳措辭禁忌

⚠️ **不可寫「被打死 / 陣亡 / 戰死」**——遊戲沒有玩家 HP,小兵不會死。
可用:未能突破 / 戰線潰散 / 時限耗盡 / 遠征止步於 / 未能阻止。
有測試 (`core.test.ts`) 直接斷言結局文字不含「死 / 殺 / 陣亡」。

### 轉生要呈現為結算與傳承,不是清空

結算頁至少要有:這一代是誰、走哪條路、抵達幾層、留下什麼、**本代帶來的永久變化**,
以及**一個已經快到了的下一個目標**。

### 圖鑑獎勵拓寬玩法寬度,不加常駐傷害

常駐傷害會造成老玩家數值膨脹、最佳解固化、圖鑑從收藏變成作業。
建議獎勵:新事件加入事件池、新裝備變體加入掉落池、開局可預覽額外命運節點、
首次重鑄免費鎖定一條詞綴、新外觀 / 稱號 / 轉職候選。

**讓遊戲越玩越寬,不是越玩數字越大。**

### 未收錄物不要顯示問號

改用剪影 + 線索(「由重型盾牌在神匠命運下進化而來」),製造目標而不是讓玩家面對一頁問號。

## 七、隨機性的位置

**固定獲得 + 隨機驚喜**:轉生後**一定獲得**勳章、圖鑑進度、鐵匠鋪經驗、一條列傳;
**可能額外獲得**傳家之器殘片、稀有稱號、裝備異變。

> 核心進度不可隨機消失,隨機只負責讓結果偶爾超出預期。

## 八、五層期待循環(驗收標準)

任何新功能上線前對照此表,確認它落在哪一層。**五層中有任何一層是空的,該版本就不會好玩。**

| 時間尺度 | 玩家期待 | 對應系統 |
|---|---|---|
| 10~30 秒 | 下一次會出現什麼 | 掉落、技能觸發、旅途事件 |
| 2~5 分鐘 | 這輪流派開始成形 | 命運節點、技能組合 |
| 10~20 分鐘 | 角色會轉成什麼 | 二轉逐步揭露、職業融合 |
| 一輪結束 | 這代留下什麼 | 傳承結算、列傳、圖鑑 |
| 多輪累積 | 我的世界發生什麼改變 | 里程碑、解鎖池、家族傳承 |

## 九、六條核心原則

1. 每次重要選擇,都必須留下可見痕跡
2. 每個長期目標,都要顯示下一個可接近的節點
3. 新能力優先改變舊能力,不只是增加數值
4. 轉生必須被呈現為結算與傳承,而不是清空
5. 隨機只提供驚喜,不阻斷核心進度
6. 永久成長優先拓展玩法寬度,而非持續堆高傷害
