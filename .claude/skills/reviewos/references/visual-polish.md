# ReviewOS Module：Visual Polish Review

**角色：Senior UI/VFX Designer（資深 UI／VFX 設計師）**
核心提問：

> 這是不是精品（AAA 品質）？

本模組是 Pipeline 的**最後一關**：只有在 System / Experience / UI / Art Direction 都通過後才值得做。方向錯的東西打磨得再亮也是錯的。所有發現轉為 Core 的 Issue 格式輸出（多數為 P2/P3，但精品感是 P2 的總和）。

## 審查項目

### Spacing / Padding
- 間距是否來自一致的 scale（4/8/12/16/24…），還是到處 magic number？
- 同類元件的內距是否完全一致？（兩張卡片 padding 差 2px，玩家說不出哪裡怪但感覺得到廉價）
- 光學對齊：icon 與文字的視覺重心對齊，而非幾何框對齊。

### Pixel Perfect
- 1x 尺寸下線條是否落在整數像素（避免半像素模糊）？
- 縮放後的資產有沒有模糊、鋸齒、壓縮痕？
- 九宮格拉伸的邊角是否變形？

### Shadow / Glow
- 陰影是否共用同一光源方向與同一套 elevation 級距？
- Glow 是否保留給語義（稀有、可互動、危險），還是到處發光導致語義稀釋？
- 疊加模式在深色／淺色背景上是否都成立？

### Motion / Ease / Animation Curve
- **禁止 linear**：所有介面動效必須有 easing。進場 ease-out、出場 ease-in 為基本文法。
- 時長級距是否成系統（如 120/200/300ms），還是每個動畫各自為政？
- 動畫曲線是否表達重量？（重物 = 慢起大慣性；輕物 = 快起快停）——與 Art Direction 的 Animation Language 對齊。
- 高頻動畫第 100 次觸發時是否仍不礙事？（爽一次的動畫可能煩一百次）
- 可跳過性：獎勵演出連點能不能加速？

### Transition（轉場）
- 畫面切換有沒有交代空間關係（從哪來、到哪去），還是硬切？
- 元素的進出場是否有序（stagger），還是全部同幀出現？
- 轉場期間輸入是否鎖定得當（防連點穿透）？

### 微回饋（Micro-feedback）
- 每個可點元素是否有 pressed 態？
- 數字變化是否滾動／跳動而非瞬變？
- 音畫是否同幀（特效與音效錯 100ms 就是「怪」的來源）？

## 審查方法

1. **逐幀檢視**：關鍵演出錄影後逐幀看，找出穿幫幀、跳幀、對不齊。
2. **並排一致性**：同類元件截圖並排，找出間距／圓角／字級漂移。
3. **降速檢視**：動畫 0.25x 播放，檢查曲線與層次。
4. **廉價感清單**：linear 動畫、default 陰影、系統字型未調字距、純黑 #000 陰影、未壓字的按鈕 pressed 態——逐項掃描。

## 固定檢查清單

- □ 間距系統一致？
- □ Pixel perfect？
- □ 光源方向統一？
- □ 無 linear 動畫？
- □ 時長成級距？
- □ 高頻動畫不礙事？
- □ 演出可跳過／加速？
- □ 音畫同步？
